# ルーティーン消化カンバン アプリ仕様書 (Routine Kanban Spec)

## 1. 概要 & 背景
- **課題**: 夜のプライベート時間に、毎日・曜日ごとのルーティーンや定期タスクの消化状況を把握したいが、たまに忘れてしまう。
- **根本原因**: 既存のToDo・習慣化アプリは多機能・過剰設計であり、ツールの仕様に生活を合わせる認知負荷が高い。夜のリラックスタイムに最小限の操作（ワンアクション）で確認・チェックできるシンプルな仕組みが必要。
- **コンセプト**: **「思考ゼロ・最小手数で完了へ放り込む」** PC向け定期ルーティーン消化カンバン。

---

## 2. システム要件 & 技術スタック
- **ターゲット環境**: PCメイン（Linux / macOS / Windows）
- **フレームワーク**: **Tauri v2** + Webフロントエンド（React / Svelte / Vue + Vite + Tailwind CSS）
  - 超軽量・省メモリで動作し、デスクトップ常駐やクイック起動に適している。
- **データ永続化**: ローカルファイル（JSON または SQLite）
  - クラウドや外部アカウント連携は不要、PCローカル完結で瞬時に起動・保存。

## 3. UI/UX 設計

### 画面レイアウト（同一画面・エリア分割）
画面遷移やタブ切り替えを行わず、1画面で「未完了の3スパン」と「共通の完了エリア」を配置。

```text
┌────────────────────────────────────────────────────────────────────────┐
│ 📅 2026/09/24 (木)                         進捗: [██████░░░░] 3/5 完了  │
├────────────────────────────────────────┬───────────────────────────────┤
│ 📋 未完了 (To Do)                       │ ✅ 完了 (Done)                │
│                                        │                               │
│ ▼ 🌞 今日のルーティーン (Daily)         │ ┌─ [毎日] ──────────────────┐ │
│ ┌────────────────────────────────────┐ │ │ 日記を書く                  │ │
│ │ 筋トレ・ストレッチ                 │ │ └───────────────────────────┘ │
│ └────────────────────────────────────┘ │ ┌─ [毎日] ──────────────────┐ │
│                                        │ │ RSSチェック                 │ │
│ ▼ 📅 今週のタスク (Weekly)              │ └───────────────────────────┘ │
│ ┌────────────────────────────────────┐ │ ┌─ [今週] ──────────────────┐ │
│ │ 部屋の掃除機がけ                   │ │ │ 爪を切る                  │ │
│ └────────────────────────────────────┘ │ └───────────────────────────┘ │
│                                        │                               │
│ ▼ 🗓 今月のタスク (Monthly)             │                               │
│ ┌────────────────────────────────────┐ │                               │
│ │ サブスクの整理・見直し             │ │                               │
│ └────────────────────────────────────┘ │                               │
└────────────────────────────────────────┴───────────────────────────────┘
```

### 操作性
1. **ドラッグ＆ドロップ**:
   - 各スパンのカードを掴んで、右側の「完了」エリアへドロップ。
2. **ワンクリック移動**:
   - カードをクリック（または完了チェックボタン押下）するだけでも、即座に「完了」エリアへ移動。
3. **元に戻す**:
   - 誤って完了にした場合も、「完了」エリアのカードをクリック or 左側へドラッグで未完了に戻せる。
4. **タスクの編集・削除**:
   - 未完了・完了カードにホバーすると表示される鉛筆アイコンから、タイトル・周期スパン・曜日・タグをいつでも編集可能。
   - 不要になったタスクはゴミ箱アイコンからワンアクションで削除可能。
5. **進捗計算（本日のノルマ基準）**:
   - **分母**: `Dailyタスク` ＋ `当日の曜日に該当する曜日指定タスク`。
   - **分子**: 上記のうち本日完了済みのタスク数。
   - **設計意図**: 来ていない曜日（土日など）のタスクが残っていても分母に含まれず、今日やるべきタスクを消化すれば100%（達成！）となり、夜の達成感を損なわない。
   - 「今週いつでも」や「月次」タスクはマイペース消化枠として扱い、消化した際は右側エリアに並びつつ「(全完了 X)」として補助カウントされる。

### ビジュアル・テーマ設計
- **テーマカラー (Solarized Light)**:
  - 夜でも目が疲れにくい、クリーム／アイボリー（`#fdf6e3`）を基調とした上質なペーパーライク・ライトテーマ。
  - テキストは深みのあるダークティール（`#073642` / `#586e75`）で高い可読性を維持。
- **曜日バッジ（7色カラーリング）＆ 曜日タスクの視覚的分離**:
  - 月曜〜日曜の各曜日に固有の識別色を割り当て、視覚的に曜日ルーティーンを判別可能。
  - 月 (紫), 火 (赤), 水 (水色), 木 (緑), 金 (黄), 土 (橙), 日 (ピンク)。本日該当の曜日にはアクティブ強調枠が付与。
  - **当日と他曜日の明確な階層化（ハイブリッド表示）**:
    - **本日の曜日ルーティーン**: 上部に配置され、青色ボーダーおよび「本日」バッジで強調。
    - **他曜日のルーティーン（今週の控え）**: 下部セクションに分離配置。カード枠を破線（dashed）、背景色・タイトル色・バッジを淡いミュートトーン（`opacity-75`）、ステータスに「他曜日」を付与して「今日はやらなくてよい待機枠」であることを一目で識別可能。マウスホバー時には「前倒し完了へ」が表示され、前倒し消化の操作性も維持。
- **タグ（コンテンツ・カテゴリ）機能**:
  - `アニメ`, `漫画`, `家事`, `健康` など任意のタグを付与し、毎週のエンタメ消化や生活ルーティーンを分類管理。

## 4. 定期タスクの周期 & 自動リセット仕様

| スパン種別 | 出現・消化ルール | リセット（未完了に戻る）タイミング |
| :--- | :--- | :--- |
| **Daily (毎日・定期)** | 毎日、または特定の曜日（例: 平日 月〜金、週末 土日など）に毎晩消化するタスク。該当曜日以外は「他曜日控え」として待機し、当日の進捗分母には含まれない | 翌日のリセット時刻（例: 毎日 深夜4:00） |
| **Weekly: Anytime (今週いつでも)** | 月曜〜日曜の1週間の間に任意のタイミングで1回消化すればOK（掃除機がけ、爪切り等） | 翌週月曜日のリセット時刻（例: 月曜 深夜4:00） |
| **Weekly: Day-of-Week (曜日指定)** | 週に1回、特定の曜日（例: 毎週 月曜のジャンプ、毎週 水曜のサンデー等）に消化するタスク。該当曜日のバッジや「本日」ハイライトを表示 | 翌週月曜日のリセット時刻（例: 月曜 深夜4:00） |
| **Monthly (月次)** | 毎月1回消化するタスク（月末締め、翌月1日リセット）。目安日（`monthlyDay`: 例 25日）を設定した場合、3日前〜当日にかけてカードが接近ハイライト表示される | 翌月1日のリセット時刻（例: 毎月1日 深夜4:00） |

> **状態保持・リセット運用ルール**:
> - 週の定義: **月曜日スタート 〜 日曜日終わり**（日曜から月曜への切り替え時に週次リセット）。
> - 月の定義: **毎月1日スタート 〜 各月末日終わり**（末日から翌月1日への切り替え時に月次リセット）。
> - 完了タスクの保持: 消化したタスク（Daily、Weekly、Monthly）は、各リセット時刻が訪れるまで画面右側の「完了 (Done)」エリアに保持され続ける。
> - 完了タグ表示: 完了エリアでは各タスクに `[毎日]`, `[月〜金]`, `[今週]`, `[月・木]`, `[毎月25日]` 等のバッジが付与され、消化状況を一目で把握可能。
> - 月次タスクの接近ハイライト: 毎月の目安日（クレカ明細、家賃等）を設定したタスクは、3日前になるとアンバーの警告枠、当日になるとローズの強調枠とバッジが点灯し、忘却を防止する。

### 自動リセット判定アーキテクチャ（遅延評価 / Lazy Evaluation）
夜にアプリを起動し、用事が終わったら閉じる利用スタイルに最適化するため、**常駐デーモンやリアルタイムの常時監視タイマーは排除**する。

1. **判定トリガー**:
   - **アプリ起動時**: Lowdbから前回の `resetState` を取得し、即座に評価。
   - **ウィンドウフォーカス時 (`window.onfocus`)**: 深夜4:00を跨いでPCを開いていた場合でも、ウィンドウに触れた瞬間に再評価して画面を最新化。
2. **深夜4:00基準の論理日付 (Logical Date)**:
   - 現在時刻からリセット時刻（デフォルト4時間）を差し引いた日時を論理基準値とする（例: 深夜1:30の起動は前日の夜として扱う）。
   - 論理日（`YYYY-MM-DD`）、論理週の月曜日（`YYYY-MM-DD`）、論理月（`YYYY-MM`）を前回の状態と比較し、進んでいれば該当スパンの完了タスクを未完了へリセット。
3. **メリット**:
   - バックグラウンドでのCPU・メモリ消費ゼロ。
   - 数日〜数週間ぶりにアプリを開いた場合でも、起動した瞬間に最新状態へ一発で追いつく。

## 6. 実装状況と今後の展望

### 実装完了機能 (v0.1)
1. **カンバンUI基盤**:
   - 画面左側（Daily / Weekly / Monthly）＋ 画面右側（Done）の1画面完結レイアウト。
   - ワンクリック完了/差し戻しおよび HTML5 Drag & Drop 移動。
   - Solarized Light基調のペーパーライクテーマ。
2. **タスク周期・属性**:
   - 週間タスクの「いつでも週1」と「各曜日指定（月曜〜日曜）」の分離。
   - 曜日ごとの7色カラーバッジおよび本日該当曜日ハイライト。
   - 月次タスクの目安日設定と接近ハイライト（3日前からパルス表示）。
   - タグ付け機能（`#アニメ`, `#漫画` 等）およびタスク編集モーダル。
3. **データ永続化**:
   - Lowdbによる単一JSONファイル永続化（Tauri FS経由でアプリ設定ディレクトリに自動保存、ブラウザ時はlocalStorageへフォールバック）。
4. **遅延自動リセット（Lazy Evaluation）**:
   - 深夜4:00境界の論理日付算出。
   - アプリ起動時およびウィンドウフォーカス時（`window.onfocus`）の自動リセット実行。
5. **進捗インジケーター & 達成ビジュアル（All Done! Empty State）**:
   - ヘッダーの円形リングゲージ（Circular Progress Ring）によるダイナミックグラデーション（ティール/シアン → ブルー → エメラルド/ゴールド）。
   - 本日のノルマ（Dailyおよび当日曜日指定Weekly）がすべて消化された瞬間に、未完了カラム内に夜のリラックスをテーマとしたSVGイラスト（三日月・温かいマグカップ・星空）と達成祝福カードを表示。パッと見で「今日のタスクがすべて終わったこと」を直感的に把握可能。
