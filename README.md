# Hibique（日々キュー）

「思考ゼロ・最小手数で完了へ放り込む」PC向け定期ルーティーン消化カンバン。

---

## 1. 概要 & コンセプト

夜のプライベート時間に、毎日・曜日ごとのルーティーンや定期タスクの消化状況を把握したいが、忘れてしまう——。
既存のToDoアプリや習慣化アプリは多機能・過剰設計になりがちで、ツールの入力や整理自体に認知負荷がかかります。

**Hibique（日々キュー）** は、夜のリラックスタイムに「思考ゼロ」かつワンアクションでタスクを完了へ放り込める、超軽量なPC向けカンバンアプリケーションです。

```text
┌────────────────────────────────────────────────────────────────────────┐
│ 📅 2026/09/25 (金) 23:15                  進捗: [██████░░░░] 3/5 完了  │
├────────────────────────────────────────┬───────────────────────────────┤
│ 📋 未完了 (To Do)                       │ ✅ 完了 (Done)                │
│                                        │                               │
│ ▼ 🌞 今日のルーティーン (Daily)         │ ┌─ [毎日] ──────────────────┐ │
│ ┌────────────────────────────────────┐ │ │ 日記を書く                  │ │
│ │ 筋トレ・ストレッチ                 │ │ └───────────────────────────┘ │
│ └────────────────────────────────────┘ │ ┌─ [金曜] #アニメ ──────────┐ │
│                                        │ │ 最新話チェック              │ │
│ ▼ 📅 今週のタスク (Weekly)              │ └───────────────────────────┘ │
│ ┌────────────────────────────────────┐ │ ┌─ [今週] ──────────────────┐ │
│ │ 部屋の掃除機がけ                   │ │ │ 爪を切る                  │ │
│ └────────────────────────────────────┘ │ └───────────────────────────┘ │
│                                        │                               │
│ ▼ 🗓 今月のタスク (Monthly)             │                               │
│ ┌────────────────────────────────────┐ │                               │
│ │ サブスクの整理・クレカ確認 (25日)   │ │                               │
│ └────────────────────────────────────┘ │                               │
└────────────────────────────────────────┴───────────────────────────────┘
```

## 2. 主な特徴

- **1画面・4エリア構成**:
  - 左カラムに「未完了（Daily / Weekly / Monthly）」、右カラムに「完了（Done）」を一覧配置。画面遷移やタブの切り替えは一切不要です。
- **直感的な操作（クリック ＆ DnD）**:
  - カードをクリックするだけで即座に完了エリアへ移動。もちろんドラッグ＆ドロップ操作にも対応しています。
- **Solarized Light カラーテーマ**:
  - 夜間のPC作業でも目に優しい、上質なペーパーライク・アイボリー（`#fdf6e3`）を基調としたデザイン。
- **柔軟な周期スパン管理**:
  - **Daily**: 毎日消化するルーティーン。
  - **Weekly (Anytime)**: 週の間に1回消化すればよいタスク。
  - **Weekly (曜日指定)**: 特定の曜日（月〜日）に消化するタスク（7色カラーバッジ＆当日強調表示）。
  - **Monthly**: 月に1回消化するタスク。目安日（例: 25日）を設定すると、3日前〜当日にかけてカードが接近ハイライトされます。
- **コンテンツタグ**:
  - `#アニメ`, `#漫画`, `#家事`, `#健康` など、任意のタグで分類管理可能。
- **遅延自動リセット（Lazy Reset）**:
  - 重たい常駐デーモンやバックグラウンドタイマーは不要。アプリ起動時およびウィンドウフォーカス時（`window.onfocus`）に、論理日付境界（デフォルト午前4:00）を判定して自動リセットします。
- **完全ローカル・単一JSON永続化**:
  - クラウドや外部DBへの接続は不要。Lowdbにより、OS標準のアプリ設定ディレクトリ内の単一JSONファイル（`hibique_data.json`）へ瞬時に保存されます。

## 3. 技術スタック

| 分類 | 技術 / ライブラリ | 用途・選定理由 |
| :--- | :--- | :--- |
| **デスクトップ基盤** | [Tauri v2](https://v2.tauri.app/) (Rust) | 超軽量・省メモリ、セキュアなデスクトップランタイム |
| **フロントエンド** | React 19 + TypeScript + Vite | 型安全で高速なモダンUI開発 |
| **スタイリング** | Tailwind CSS + Lucide React | 高速スタイリングとシンプルなUIアイコン |
| **データ永続化** | Lowdb 7 (Custom Tauri FS Adapter) | 単一JSONファイルによる透明・軽量なローカルストレージ |
| **環境管理** | [mise](https://mise.jdx.dev/) + pnpm 12 | Node.js, pnpm, Rust, Tauri CLI の統一管理 |
| **バージョン管理** | Jujutsu (jj) / Git | 柔軟な変更追跡と作業コピー管理 |

## 4. 開発・実行方法

### 前提条件
- [mise](https://mise.jdx.dev/) がインストールされていること（または Node 24+, pnpm 12+, Rust latest がセットアップ済みであること）

### セットアップ

```bash
# ツールチェインのインストール (mise使用時)
mise install

# 依存パッケージのインストール
pnpm install
```

### 開発モードの起動

```bash
# Tauri デスクトップアプリとして起動
pnpm tauri dev

# WebブラウザのみでモックUIを起動する場合
pnpm dev
```

### プロダクションビルド

```bash
# デスクトップバイナリ（インストーラー/実行ファイル）のビルド
pnpm tauri build
```
